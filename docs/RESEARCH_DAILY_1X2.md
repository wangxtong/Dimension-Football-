# 每日研究级胜平负预测｜双轨验收契约

2026-11-02 用户变更范围。本文是 Draft PR #65 的候选实现说明，不表示已合入 main 或上线。

## 产品双轨

- **普通1X2研究：** 每日根据真实赛程、可见历史、冻结模型输入输出三概率和研究方向；明示“研究参考，非投注建议”。不需要两个独立盘口源或初盘作为建模前提。
- **严格盘口候选：** 单独要求真实独立双源、供应商原生初盘、有效双方报价、时钟与SHA；0场就是0场，不能拿普通模型概率补第二来源。
- **原正式预测出口：** 商用 RELEASE_GATE=BLOCKED 维持，不修改正式 Telegram 或正式预测发布接口。用户取消的会员/订单/支付/营销功能不在范围。

## 研究日报与调度

- 北京时间每天10:10对应UTC02:10。GitHub Actions 研究模式先尝试已冻结预测的赛后FT核账，再做当日赛事研究冻结。原观察任务仍按独立调度。
- 从真实持久研究账本生成 reports/research-daily/latest.json 和 latest.md，缺数据、无法读回或无合格比赛保持0，不伪造。
- 每日、7天、30天按北京时间开球日统计：合格冻结、已评分、等待FT、取消/改期/其他作废；命中率仅以实际已评分的比赛为分母，另给Brier和LogLoss。
- 同一源真实fixtureId只选最早合格赛前冻结，必须有reportId、predictionId、模型/训练SHA、真实生成/登记时间、有效期；晚于开球或不明身份一律排除。
- 原生FT必须在开球后实际观察/登记。赛后回填的历史比分不准补造赛前预测；比分修订允许复核但不可改原冻结概率；时间无效fail-closed。
- Web研究报告另存独立带reportId的不可变快照，仅登录用户可取；GitHub机器OIDC写入且GET回读，不能通过正式预测发布路径。**研究开关有两个独立控制面**：GitHub Actions仓库变量 `vars.VANTIS_RESEARCH_WEB_ENABLED` 控制上传；Site Worker运行环境 `env.VANTIS_RESEARCH_WEB_ENABLED` 控制机器GET/POST、登录用户API与HTML/JS资源读取。两端都必须经独立验收后明确配置为字符串 `true`；GitHub变量**不会自动同步**到Site env。Site环境开关默认缺省或 `false` 时全部研究端点返回404（包括已存Bucket旧报告），首页隐藏研究入口；旧正式发布/观测接口不随该开关变更。紧急撤销优先关闭Site Worker env，并验证历史研究数据无法再读取；保留原始证据不删除。
- 不自动发送研究Telegram；研究站点与商业预测出站完全隔离，当前正式预测外发保持BLOCKED。GitHub cron成功或配置存在不代表7天G1/真实24小时持续运行。

- 原PR只在GitHub采集端关闭上传，Site已存研究快照仍可被已登录用户读取；这不是已证实的生产事件。
