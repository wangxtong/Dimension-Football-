# 智能体审计任务与验收

来源：[维度足球全面实测审计](https://chatgpt.com/space/page_ed7380a0df008191bfcc39c3931b63d0)，审计基线 `2fb4007e4c92ca26ac2d538c1714b136a68f9e83`，2026-10-30 UTC。以下是历史审计产生的修复任务，执行前需在当前分支复核。本次角色配置不包含业务缺陷修复。

机器状态与角色路由保存在 [config/agent-workflow.json](../config/agent-workflow.json)。状态定义：open 尚未完成当前版本复核和修复；in_progress 正在处理；verified 有修复提交、复现与回归证据。只有代码验证、没有线上条件时，缺陷可按本地验收关闭，但必须另列生产未验证项。

| 编号 | 优先级 | 状态 | 负责人 | 复核 | 历史复现与关闭条件 |
| --- | --- | --- | --- | --- | --- |
| A01 | P1 | open | reliability | QA、运维 | 深度 15 次请求全失败仍 exitCode=0；深度阶段取消也返回 0。关闭要求完整生命周期退出状态正确，取消/全局失败非零，预期缺项不误判。 |
| A02 | P1 | open | security | QA | 隔离副本的嵌套 `.env.production` 被打入 ZIP。关闭要求敏感变体不入包、合法源码可用，并检验符号链接与未跟踪文件边界。 |
| A03 | P2 | open | reliability | QA、运维 | 第一轮暂停于深度阶段，第二轮同 state/out 可完成。关闭要求互斥覆盖完整阶段并验证报告原子发布与中断恢复。 |
| A04 | P2 | open | data-quality | QA、研究 | 30 天旧伤停与首发仍 reported。关闭要求按维度定义时效，过期/未来/缺失时间明确，历史赛果保留正确时间语义。 |
| A05 | P2 | open | data-quality | QA、采集 | total=2 仅一页且样本足够时 history available、missing 为空。关闭要求缺页状态传递至逐场结论，完整分页正常。 |

## 实施顺序

优先 A01 与 A02；A01/A03 作为可靠性任务统一写入 run.mjs，A04/A05 作为质量任务统一写入 full-report.mjs。可靠性、打包、质量三个写入范围独立时可并行；修改公共契约时先由协调者确定依赖。每组完成后由 QA 复核同一提交。

## 独立的生产与能力任务

这些事项不能仅靠修复 A01–A05 关闭：

| 事项 | 负责人 | 必需证据 |
| --- | --- | --- |
| 确认实际调度位置 | operations | Actions、ECS 或旧计划的当前状态，防止重复启用 |
| 完成正式 API 一轮验收 | collector、operations | 已授权凭据、5 联赛真实响应、源时间、缺项、配额 |
| 第二独立盘口来源和初盘 | collector、research | 来源独立性、同场同盘、完整双边报价、真实早期轨迹 |
| 配额和持续续查 | collector、reliability | 实际套餐限制、缓存/节流、跨轮逐维度进度 |
| 生产监控和恢复 | operations | 当前部署提交、成功真实采集时间、磁盘/备份、恢复验证 |
| 预测效果评估 | research、data-quality | 不可变赛前预测、赛果、时间切分、样本量与校准指标 |

审计当时 160 项测试通过，6 次可见 schedule 均 skipped，唯一成功采集为 demo；公开源探测经代理得到 503。以上均是特定时间证据，不代表当前生产状态。缺少 API/ECS 访问时先完成本地可验证工作，报告真实阻塞，不能虚构上线或准确率。

## 关闭记录格式

```text
编号：A01
状态：verified 或仍 in_progress
修复提交：实际 SHA
复现：输入、环境、原错误行为
修复后：目标行为、实际命令与结果
回归：范围与结果
复核方式：独立角色或顺序自审，写明实际情况
生产验收：通过/失败/未验证及原因
证据位置：仓库测试、CI 链接或可访问报告
```
