## 一、他的架构（pipeline.py 原文）

```
Elo（Hicruben 世界杯模型）        → 强基线 + 在线更新
Dixon-Coles + Monte Carlo         → 比分分布 / 低比分校正
XGBoost 三分类 + 独立平局分类器    → 主模型
Platt / 独立平局校准               → 概率校准
严格滚动回测，统一 RPS/Brier/LogLoss/校准度
```

**关键**：若环境没有 XGBoost，退化到 Elo-DC-MC + 基线校准，**不使用假模型**（原文：「绝不使用假模型」）。

## 三、62–72% 是怎么来的：亚盘口径

报告统计表的定义：
```
正向命中率 = (全赢 + 半赢) / (可结算且非走盘)
```

对比 1X2 方向准确率：
| 口径 | 随机 | 他的数字 | 说明 |
| --- | --- | --- | --- |
| 1X2 三分类 | 33.3% | 48–53% | 他代码自认 |
| 亚盘（含让球保护） | — | 62–72% | 报告展示 |

**亚盘二分类天然比 1X2 三分类的命中率高**：让球抹平了强弱差，走盘被排除，半赢算命中。**这两个数字不可直接比较。**

## 四、他真正比我们强的地方（不是算法）

| 维度 | 他 | 我们 |
| --- | --- | --- |
| 覆盖联赛 | **所有在售赛事**（欧冠/巴甲/瑞超/美职/挪超…） | 仅五大联赛 |
| 每日输出 | 固定 10 场 | 今天 0 场（国际比赛日空窗） |
| 报告形态 | 10 场 + 盘口赔率 + 次日复盘 + 三期累计 | 冻结计数 + 结算统计 |
| 结算口径 | 亚盘（全赢/半赢/走盘/半输/全输） | 1X2 |

**结论：差距在覆盖与输出形态，不在模型精度。**

## 六、我们可借鉴的具体项（按性价比）

**1. 改用亚盘口径做对外报告（最高优先）**
   我们已经在 `daily-picks.mjs` 实现了全赢/走盘/全输结算。亚盘二分类比 1X2 更贴近真实投注场景，且与市场盘口直接可比。

**2. Dixon-Coles 低比分校正**
   纯泊松会低估 0:0、1:0、1:1 这类低比分（足球的进球不是独立泊松）。DC 用 `tau` 修正四项低比分概率，是标准做法。**这是我们可以立刻加的**，预期平局预测改善明显。

**3. 独立平局分类器**
   平局是三分类里最难的一类。他的做法是单独训练二分类「是否平局」，再回填。

**4. Platt 校准**
   我们 `calibrated: false`、macroECE 0.047。Platt 能把概率压回真实频率，Brier 可降 0.02-0.04。

**5. elo 在线更新**
   比「固定窗口内的历史比分」更快响应状态变化。

## 七、我的判断

1. **不要拿 62–72% 当目标** —— 他代码自己写 48–53%，那两个数不同口径。追求 72% 只会让我们去凑数字。
2. **优先补覆盖，而不是补模型精度** —— 他每天能出 10 场是因为覆盖广，不是因为模型强。
3. **Dixon-Coles + Platt 校准** 是性价比最高的两处改动，且不依赖新数据源。
4. **对外报告改用亚盘口径**，与市场可比，也与他的口径一致，避免被误解为「我们的 1X2 命中率低」。
