# 维度足球｜七层项目架构（唯一A1角色）

本项目业务架构仍为七层，**只保留 A1 项目总控审计总监**；不再按照A编号拆分独立智能体。此处所有模块由A1统一总控、审计、在授权范围内修复及验收协调；专业独立复核是验收环节，不等于新增常驻角色。

| 模块 | 保留的产品能力 | 最低可复核验收 |
| --- | --- | --- |
| ① 信息源采集 | 五大联赛赛程、历史FT、独立盘口、真实初盘、限流冷却 | 来源许可、实时HTTP、RAW哈希、独立源组与覆盖/失败分母 |
| ② 数据中心 | 队伍赛事统一ID、来源时点、修订、持久存储 | 身份与UTC校验、归档读回及不可变原件 |
| ③ 预测与分析 | 1X2、大小球、亚洲盘口研究 | 无赛后泄漏、独立赔率与模型来源可回放 |
| ④ 模型评估 | 回测、概率校准、赛前冻结、官方FT结算 | 固定分母、对应提前量、同场A/B、真实评分 |
| ⑤ 推荐与审核 | 今日优选/普通研究、发布资格和限权 | 资格不达标可以0场；商业 `BLOCKED` 不绕过 |
| ⑥ 用户交付 | 中文Cloudflare Web、Telegram消息/按钮 | 同reportId、摘要、平台回执及重复发送保护 |
| ⑦ 总控运维 | GitHub CI、运行监控、Cloudflare存储/回滚 | 同源SHA、必需测试全绿、线上核验、真实回滚 |

A1负责所有七层，无独立A编号子角色。关键修改仍由外部合格独立审查者或可复算的独立CI证据验证，A1不能单方面把其修改判为通过。档案中的历史角色归属不代表仍有活动智能体。

业务正式 `RELEASE_GATE=BLOCKED`；不要把部署存在或模型能生成概率解释为已达到商业预测准确率。
