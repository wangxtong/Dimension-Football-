# 维度足球项目框架与岗位归属

本文件将用户确认的七层架构落实为模块责任和验收边界。岗位指令与机器可读映射以 [agent-team.json](../config/agent-team.json) 为入口。A1 为项目总监，A8 独立验收；配置岗位不代表功能已经完成或后台智能体正在运行。

```text
维度足球
├─ ① 信息源采集
│  ├─ 联赛赛程、历史比赛、终场结果
│  ├─ 独立盘口来源、初盘与最新报价
│  └─ 探活、限速、冷却、失败切换
├─ ② 数据中心
│  ├─ 球队／赛事统一身份
│  ├─ 原始数据、来源时间、修订记录
│  └─ 持久存储、快照、归档恢复
├─ ③ 预测与分析
│  ├─ 胜平负概率模型
│  ├─ 大小球分析
│  └─ 亚洲盘口证据审核
├─ ④ 模型评估
│  ├─ 历史回测、基准比较、概率校准
│  ├─ 赛前预测冻结、赛后核账
│  └─ 分联赛、分提前量的质量报告
├─ ⑤ 推荐与发布审核
│  ├─ 今日优选、普通分析、暂不可评估
│  └─ 数据资格、模型资格、版本发布门禁
├─ ⑥ 用户交付
│  ├─ 中文 Web 看板
│  └─ Telegram 分类消息、按钮、发布回执
└─ ⑦ 总控与运维
   ├─ 八角色协作、进度及证据台账
   ├─ GitHub CI、制品、部署、监控、回滚
   └─ Sites／阿里云 ECS
```

| 层级 | 最终负责人 | 协作及子项归属 | 最低交付与验收 |
| --- | --- | --- | --- |
| ① 信息源采集 | A2 | A3 接收数据；A5 核验独立渠道及初盘真实性 | 真实原文、时间、使用范围、逐联赛覆盖和故障恢复证据；采集到初盘字段不代表初盘已验证 |
| ② 数据中心 | A3 | A7 负责存储、容量、备份恢复；A3 负责数据语义和溯源 | 稳定身份、时间版本、修订及可按摘要取回的冻结输入 |
| ③ 预测与分析 | A4 | A5 独立负责亚洲盘口证据审核 | 可复现的胜平负/大小球研究；严格盘口资格不限制普通 1X2 的独立评估 |
| ④ 模型评估 | A4 | A3 提供数据；A8 独立复算；A1 决定晋升 | 固定提前量、时间切分、赛前冻结及赛后核账；分联赛样本、指标、区间和缺口 |
| ⑤ 推荐与发布审核 | A5 | A4 提供普通预测质量证据；A1 负责版本及正式发布裁决；A8 独立验收 | 策略预先固定并可回放；明确优选目标；目标3–7场允许不足或零场 |
| ⑥ 用户交付 | A6 | A7 负责运行配置；A8 验收手机/桌面及完整链路 | 中文四区看板与TG分类按钮、真实年龄和缺项、同reportId/摘要、防重和平台回执 |
| ⑦ 总控与运维 | A1 | A7 负责CI、制品、部署、监控、回滚和运行保障；A8 独立验收 | 唯一任务负责人、实际版本、完整证据；所有远端变更由总控统一执行 |

A1 实现的关键变更由 A8 复核。A8 实现的关键修复由 A1 指定另一名具备相关专业能力的角色复核，不能自行验收。

第⑤层中，A5只消费A4经独立验收的概率与可评估状态进行策略分类，不修改或审批普通概率，也不以盘口缺项否决普通1X2。模型资格由A4提交、A8独立复核、A1裁决；A6负责对应分类的实际展示。

## 当前工作边界
- 线上版本以远端和生产回读为准，R3 本地分支及未提交文件保留，未经验收不夹带发布。
- 当前正式预测 `RELEASE_GATE=BLOCKED`。工程回归、研究采样和商业模型资格分别报告。
- 当前采用会话内监督，最多7个并发含总监；八岗位分批交接，不承诺无人值守持续运行。
- 每环节用 [进度模板](agents/PROGRESS-TEMPLATE.md) 交付修复前后效果、实测、剩余缺口和下一步。
