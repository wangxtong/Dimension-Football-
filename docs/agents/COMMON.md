# 八岗位共同指令

你参与 `wangxtong/Dimension-Football-` 的商业级升级。核心是可靠信息源、可复现预测质量及可审计交付。先读根目录 AGENTS.md、本文件、config/agent-team.json 和分配给你的岗位文件；具体任务中的版本、范围和证据要求同时适用。

## 执行纪律
1. 明确区分本地实现、测试通过、远端合并、生产部署与生产验收；不靠任务状态宣布完成。
2. 每项任务只有一个最终负责人；开始前固定输入、输出、验收条件、文件边界和交接对象。
3. 在独立工作区开发，保留已有修改。共享接口、入口、工作流由 A1 协调。
4. 发现错误、数据异常、失败测试或依赖阻断立即向 A1 报告；暂停受影响发布，保留证据和可用服务。
5. 不伪造数据、初盘、独立来源、胜率、收益、测试及部署记录；不删测试、隐藏日志、降低阈值或挑选测试集制造全绿。
6. 普通 1X2 模型独立于严格盘口资格；今日优选目标 3–7 场，资格不足允许少于 3 场或零场。
7. 尊重来源授权、robots、登录及付费权限，所有网络请求遵守统一限速、预算和冷却。
8. 凭据通过已授权的安全绑定复用，不写进源码、提示词、报告、制品或日志。
9. 真实仓库同步、合并、采集、通知和部署由 A1 统一安排执行。子智能体不得自行实施远端变更。
10. 按同一版本核对全部必测、对应冻结回测和日志。失败、跳过、样本不足分别记录；正式预测持续 BLOCKED，直至独立数据、模型及发布资格验收。
11. 技术修复、研究采样、模型晋升、正式推荐分别报告验收范围。角色配置、测试退出码和人工 GREEN 都不是发布凭证。
12. 接受任务先返回岗位、任务、范围、交接人和阻断；每完成环节按 PROGRESS-TEMPLATE.md 报告。
13. 有关工具或技能仅按实际能力使用。首次使用技能读取其 SKILL.md；缺少技能时先检查现有可用工具，不虚报安装或绕过权限。
14. 当前采用会话内监督执行，最多 7 个并发智能体含总监；八岗位分批工作，不宣称八个常驻后台进程或无人值守监督已启用。

## 状态和证据
待开始 pending → 进行中 active → 待复核 review → 已验证 verified。
阻断 blocked 必须记录依赖、影响、负责人和下一步；仅有提交或测试时停留 review。
已验证必须附版本、时间、范围和独立验收证据。执行是否成功、产品是否可用、商业资格是否通过分别记录。

## 工具与技能选择
- GitHub：仓库、提交、PR、CI 和日志，优先现有连接器。
- 来源研究：Firecrawl 检索和读取官方文档；采集代码使用现有受控 HTTP/Crawlee/Playwright 路径。
- 网站：Sites 技能和现有站点身份；未经 A1 集成不得自行部署。
- 环境：Cloud Environment runtime 技能，先核对身份与网络授权；不把历史连接当当前授权。
- 不因岗位名称引入新付费服务、OpenAI API 调用或自动安装无关插件。
