# 维度足球商业验收合同

总控 A1 维护本合同与逐环节证据。版本：2026-10-31 R1。当前正式发布 `BLOCKED`；本文件、CI 成功或人工修改状态不构成放行凭证。

## 产品闭环与先后顺序

来源授权及原始数据 → 赛事身份和时间版本 → 历史回放与赛前冻结 → 独立赛后评分 → 发布资格 → Web/Telegram 同版本交付。

优先级：首先稳定真实数据和交付，其次证明预测质量，最后开放商业推荐与会员收费。看板先呈现真实历史回测、模型对基准可视化、当前赛事和今日优选四个区域；数据不足显示数量与原因。今日优选目标 3–7 场，资格优先于数量，允许 0 场，不降低时效、校准或独立来源标准凑数。

## 验收证据

| 关口 | 必须取得的证据 | 当前缺口与责任 |
| --- | --- | --- |
| 数据来源 | 五联赛分别列有效赛程、历史、结果覆盖；原始样本、许可/商业使用范围、供应商和取得时间；失败冷却/恢复实测 | A2/A3：当前真实历史仅德甲；其他四联赛免费赛程不代表完整覆盖；商业权益须独立核验 |
| 数据时效 | 按实际源时间计算年龄；赛程目标 15 分钟、盘口沿用 5 分钟门槛；延迟标过期；连续运行记录成功率和延迟分位数 | A2/A7：Actions 不保证准点，单次成功不构成调度 SLO 达标 |
| 盘口证据 | 同场同市场双边、真实独立渠道、初盘档案及时间因果性；停盘和冲突阻断 | A5：第二独立源、真实初盘仍不足；镜像和同上游转售不得重复计票 |
| 预测可复现 | 同一冻结输入和完整模型哈希可复算；1/24/72/168 小时分组；训练、特征、结果均遵守当时可见性 | A3/A4：修订后的历史快照只能标回顾评估，不能冒充当时可见或前瞻 |
| 模型质量 | 每联赛至少 200 场真实前瞻结算仅为初始样本下限；独立时段对照基准，报告准确率/Brier/Log loss/可靠性分箱、区间、覆盖和弃赛率 | A4：五联赛当前严格前瞻样本为 0；无充分概率校准；不能承诺 62%/70% 或收益 |
| 模型提升 | 预先固定主指标和训练/校准/测试时段；同一评估集做配对比较；保留失败实验；禁止反复选择测试集最优后称独立验证 | A4/A1：当前只有一个可核验模型快照，不绘制虚构版本增长曲线，不把多个提前量的重复赛事加成新样本 |
| 用户交付 | 当前赛事与历史报告分开，中文/北京时间/数据年龄明确；登录、移动端和错误恢复通过；Web 与通知对应同报告 ID 和摘要 | A6/A8：观察流已实测；正式预测受发布资格限制，平台接收不等于用户已读 |
| 运维与回滚 | 完整部署 SHA、制品摘要、重启持久化、备份恢复和回滚现场记录；所有自动入口执行同一门禁 | A7：Sites+Actions 为当前观察路径；ECS 尚无新版现场运行证据 |

胜平负、大小球、亚洲盘口是不同验收任务。胜平负基础模型不依赖亚洲盘口，但正式概率仍须独立质量验收；盘口候选必须额外满足自身证据门槛。新增特征或算法先进入研究比较，不能因名称更复杂直接替换基线。

## 八角色执行与总控监控

| 角色 | 输入与交付 | 相互依赖 |
| --- | --- | --- |
| A1 总控 | 固定合同、任务归属、证据账本、合并和发布裁决；每环节记录前后效果/实测/下一步 | 审查全部角色产物，不以任务状态代替证据 |
| A2 来源 | 传输健康与有效覆盖分开；限速冷却、能力隔离与授权证据 | 向 A3 提供真实原始数据和时间 |
| A3 数据 | 稳定身份、修订历史、输入摘要与去重；支持看板数据契约 | 为 A4/A5 提供同场绑定和当时可见数据 |
| A4 模型 | 基线、前瞻结算、配对比较、校准诊断及不确定性 | 不混合联赛、模型版本或重复提前量样本 |
| A5 盘口 | 上游独立性、完整市场、最新盘/初盘的时间因果性 | 缺证据继续阻断，不替代普通模型评分 |
| A6 发布 | 原子版本、幂等、平台回执、中文 Telegram 卡片及实际链接 | 接收已获准报告，观察与正式发布分离 |
| A7 运维 | 持久状态、制品边界、运行 SHA、恢复/回滚证据 | 不把本地包或网站部署称为 ECS 已上线 |
| A8 网站与 QA | 商业看板、历史可视化、权限、移动端、真实浏览器回归 | 对照 A1 指定版本及 A4 的可核验指标 |

角色采用分批智能体执行，受并发上限约束；不宣称持续有八个后台 AI 在线。总控监控依据提交、测试、生产观测与明确阻断项。每次生产观察只能证明该时刻和该范围，持续可靠性必须积累跨轮证据。
