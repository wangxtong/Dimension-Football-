## 统一交接与状态

每项交接记录issue/stage/owner/reviewer、base/head完整SHA、契约版本、测试命令/退出码、CI URL及实际CI SHA、环境与观察时间、证据URI和SHA-256、限制、下一责任人和解除阻断条件。

生产证据另含实机/站点版本、制品摘要、reportId/reportHash及回读时间；观测投影另核originReportId，不能混淆原研究ID。模型证据另含数据集/model hash、真实登记时间、各联赛/市场样本/弃赛和基准。合并后的新SHA须重新验证，不能继承旧CI。

进度pending → active → review → verified；代码、真实回测、部署和交付分开判定。FAIL/WARN_BLOCKING/UNKNOWN/BLOCKED/BACKTEST_INSUFFICIENT均不算商业全绿。当前7个既有契约测试文件的离线测试通过不改变生产或模型状态。

## 用户实测与最终验收

用户允许A1在真实测试入口及前置检查就绪后通过ChatGPT邀请实测，附地址、候选版本、操作步骤、预期结果和限制。同版本同范围避免重复提醒。正式预测尚阻断时，只邀请明确的观测/隔离功能测试；“可以实测”不等于“商业验收通过”，不发送未授权真实频道预测。

只有来源、模型、质量、部署和交付全部满足冻结的商业标准，A1才可给最终交付结论。A9只留架构交接证据，不重复发送实测或全绿通知。不保留/公布密码、Token或供应商秘密。
